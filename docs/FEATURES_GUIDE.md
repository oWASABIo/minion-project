# Builder Features & UI Guide (v1.2.0)

This guide explains how to use the latest professional features in the **Minions AI Builder** to create high-quality, multi-page projects with integrated e-commerce.

---

## 🎨 Global Design & Theme Switcher

The **Global Design** system allows you to transform the entire look and feel of your project in a single click.

### How to use:

1.  Locate the **Global Design** button at the top of the left sidebar.
2.  Select from a variety of **Curated Themes** (e.g., Midnight Pro, Forest Minimal).
3.  Each theme automatically applies a harmonized:
    - **Color Palette**: Primary and accent colors for all components.
    - **Typography**: Matching font families for headings and body text.
    - **Theme Mode**: Toggles between Light and Dark mode.
    - **Design Tokens**: Standardized border-radius and spacing.

> [!TIP]
> Use the **Forest Minimal** theme for a sleek, nature-oriented professional look, or **Ruby Clean** for high-impact marketing pages.

---

## 📄 Multi-page Management

You can now build complex websites with multiple pages and seamless navigation.

### Page Controls:

- **Navigation**: Use the **Pages** section in the sidebar to switch between different pages of your project.
- **Add Page**: Create new pages (e.g., "About", "Services") which will inherit the global design settings.
- **Inter-page Linking**: Any button or link in a section can be set to navigate between your pages.
  - Select a section -> Find the button field -> Choose **Internal Link** -> Select the target page.

---

## 🛒 E-commerce Power-up

The builder now supports functional e-commerce workflows without requiring a complex backend setup.

### Shopping Cart:

- **Toggle Cart**: In the **Global Design** settings, you can enable or disable the shopping cart visibility site-wide.
- **Real-time Totals**: The cart automatically calculates totals, shipping, and tax based on the selected items.

### Functional Buttons:

- **Add to Cart Action**: CTAs and Product sections now have a dedicated **Action** picker. Set it to "Add to Cart" to make the button functional instantly.
- **Size & Quantity**: Product detail views include fully interactive size selectors and quantity controls that sync directly with the cart.

### Manual vs. WordPress Data:

- You can toggle between using live data from a WordPress/WooCommerce backend or defining **Manual Products** directly in the sidebar for rapid prototyping.

---

## 🛠 UX Tips

- **Structure View**: Use the Structure list to reorder sections via drag-and-drop.
- **Image Previews**: Paste an external image URL (e.g., from Unsplash) into any image field to see a real-time thumbnail preview in the sidebar.
